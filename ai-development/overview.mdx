## The tools landscape

| Layer | Repo / tool | What it owns |
| --- | --- | --- |
| **Universal config** | [Shared instructions](/automation/repos/ai-llm-prompts) | Shared rules for every AI tool |
| **Hosted models** | Claude Code, Antigravity (`agy`), GitHub Copilot | The IDEs and CLIs that do the work |
| **Local inference** | MLX | Apple Silicon-native model inference for typo fixes, quick edits, no cloud tokens |
| **Extensions** | [Claude Code plugins](/ai-development/claude-code-plugins), `claude-code-routines`, `ai-workflows`, `raycast-smart-issue` | Commands, scheduled agents, Copilot workflows, Raycast UI on top of MLX |

## Model routing

Each model has a sweet spot, and work is routed to a tier with the needed
capability. Deep reasoning and multi-file refactors go to a strong model.
Line-level completions go to a fast model, and trivial work can use local
inference to limit cloud calls.

[Model routing](/ai-development/model-routing) covers how that choice is
made and governed. One endpoint sits in front of every backend, and callers ask
for a role instead of a model name. It also covers the difference between a
spend control that is enforced and one that is merely advised.

Shared routing rules live in the instructions catalog and arrive through its
`instructions` flake package. See [Repo boundaries](/ai-development/repo-boundaries)
for how instructions, plugins, and docs are split across repositories.
