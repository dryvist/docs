## Configuration

Projects and configurations define secret scopes. Access policy, rotation, and audit settings apply per project.

## Anti-patterns and best practices

- Do not store the same value in two places. One source of truth per secret.
- Rotate the service tokens at 90 days. The rotation runbook lives in [secrets-sync](/security/secrets-sync#best-practice-rotation-cadence).
- Audit log: enable Doppler's per-project audit log; review on every key rotation.
