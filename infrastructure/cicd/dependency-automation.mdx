## Master and repo config

[JacobPEvans/.github](https://github.com/JacobPEvans/.github) is the single master for Renovate presets and
reusable workflows. The master preset is `github>JacobPEvans/.github`. It owns [`renovate-presets.json`](https://github.com/JacobPEvans/.github/blob/main/renovate-presets.json)
and [`renovate-nix.json`](https://github.com/JacobPEvans/.github/blob/main/renovate-nix.json).
Consumer configs extend the master with one `extends` line, then list only repo-specific holds. They
do not set `schedule`, `timezone`, or `automergeSchedule`. `dryvist/.github` is being retired, and no
consumer extends it.

## Schedule and grouping

- Non-security dependency update PRs open Saturday from 12:00 to 15:59 UTC.
- Renovate's built-in `group:all` opens one PR per repo, with majors included.
- Renovate vulnerability alerts open security PRs Wednesday or Saturday from 12:00 to 15:59 UTC.
  They have no release-age hold.
- Release-age holds and auto-merge tiers are in
  [SECURITY.md](https://github.com/JacobPEvans/.github/blob/main/SECURITY.md#dependency-trust).

## Nix flake locks

Nix repos also extend the shared [`renovate-nix` preset](https://github.com/JacobPEvans/.github/blob/main/renovate-nix.json).
Renovate's `nix` manager and `lockFileMaintenance` relock `flake.lock` in the Saturday window. The old
custom flake-lock workflows are removed.

## Container image pins

One shared custom manager tracks `*_image:` keys in Ansible role defaults. It accepts quoted,
unquoted, and folded values, with an optional `sha256` digest. Use concrete tags, not `latest` or
`stable`.

## Dependabot security updates

Dependabot security updates are off, so Renovate is the only source of security PRs. Dependabot alerts stay on, and
Renovate reads them.
